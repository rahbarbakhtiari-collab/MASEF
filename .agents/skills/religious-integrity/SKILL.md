# Religious Integrity Workflow

1. Locate the approved source registry and version.
2. Never invent or infer a citation.
3. Treat Arabic reference text as immutable data.
4. Compare record counts and checksums before and after changes.
5. Report every textual difference, including spacing or Unicode normalization.
6. Require human religious review before release.
7. Add regression tests that prevent the same integrity failure.
