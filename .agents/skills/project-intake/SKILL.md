# MASEF Project Intake

1. Read `PROJECT-CHARTER`, `RISK-PROFILE`, `REQUIREMENTS`, and `ACCEPTANCE-CRITERIA`.
2. Ask one high-impact question at a time.
3. Separate problem, desired outcome, proposed solution, constraints, and assumptions.
4. Challenge the proposal using simplicity, security, cost, reliability, speed, scalability, and maintainability.
5. Record decisions in repository documents.
6. Stop before architecture or coding until G0 and G1 are approved.
