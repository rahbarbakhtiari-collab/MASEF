# پروفایل محصول دینی

این پروفایل باید در کنار پروفایل فنی استفاده شود.

## کنترل‌های اجباری

- Source Registry
- Dataset نسخه‌بندی‌شده
- Checksum/Hash داده مرجع
- تست شمارش و یکپارچگی
- ثبت مترجم/مصحح/منبع
- Diff متنی قابل بررسی
- ممنوعیت تولید منبع حدسی
- تأیید انسانی Religious Integrity Gate
- Rollback فوری محتوای منتشرشده

## سطح خطر

وجود متن قرآن یا حکم/فتوای قابل انتساب، به‌صورت پیش‌فرض سطح بررسی دینی را بالا می‌برد؛ حتی اگر خطر امنیتی پروژه کم باشد.
