# پروفایل سرویس API

## کنترل‌های افزوده

- قرارداد OpenAPI یا Schema معادل
- اعتبارسنجی درخواست و پاسخ
- احراز هویت و مجوز در هر Endpoint
- Rate Limit
- Idempotency برای عملیات حساس
- Versioning و سیاست سازگاری
- Timeout، Retry و Circuit Breaker برای سرویس خارجی
- تست قرارداد و بار
- لاگ Correlation ID بدون داده حساس
