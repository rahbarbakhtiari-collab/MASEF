# پروفایل عمومی

برای نرم‌افزارهایی که پروفایل تخصصی ندارند.

## کنترل‌های پایه

- Git روی شاخه کاری
- تست متناسب با خطر
- CI برای پروژه استاندارد و بحرانی
- امنیت پایه ورودی، خروجی و اسرار
- راه بازگشت متناسب با اثر تغییر

## تناسب فرایند

- سطح سبک: پیاده‌سازی، تست و گزارش کوتاه کافی است.
- سطح استاندارد: برنامه مختصر، CI و Smoke لازم است.
- سطح بحرانی: کنترل امنیتی، شواهد و بازگشت کامل‌تر اجرا شود.

Staging، Backup کامل، بازبینی مستقل و Evidence Pack فقط وقتی اجباری‌اند که خطر واقعی یا نوع تغییر آن را لازم کند.
