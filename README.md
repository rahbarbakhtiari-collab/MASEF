# MASEF — چارچوب مهندسی نرم‌افزار عامل‌محور مناهل

**نسخه:** 0.1.0  
**تاریخ مبنا:** 2026-07-24  
**هدف:** ساخت نرم‌افزار با اجرای فنی کامل توسط Codex، بدون کدنویسی دستی مالک محصول، همراه با کنترل انسانی، آزمون خودکار، شواهد قابل بررسی و امکان بازگشت.

## مدل عملیاتی

```text
Human-governed → Agent-executed → Evidence-verified → Reversible-by-default
```

- انسان: مسئله، اولویت، محدودیت، صحت دینی، پذیرش خطر و مجوز انتشار را تعیین می‌کند.
- Codex: پژوهش فنی، طراحی، کدنویسی، تست، مستندسازی و آماده‌سازی انتشار را انجام می‌دهد.
- سامانه کنترل کیفیت: هر ادعا را با تست، گزارش، لاگ و بسته شواهد بررسی می‌کند.
- انتشار: فقط پس از عبور از دروازه‌های کیفیت و وجود راه بازگشت انجام می‌شود.

## شروع سریع

1. این مخزن را کپی کنید.
2. فرمان زیر را اجرا کنید:

```bash
python scripts/bootstrap_project.py \
  --name "نام پروژه" \
  --slug "project-slug" \
  --profile wordpress-plugin \
  --profile religious-product \
  --output ../project-slug
```

3. وارد مخزن جدید شوید و اعتبارسنجی کنید:

```bash
python scripts/validate_framework.py
```

4. فایل `START-HERE.md` را از ابتدا تا انتها اجرا کنید.
5. Codex را ابتدا در حالت امن اجرا کنید:

```bash
codex --sandbox workspace-write --ask-for-approval on-request
```

## پروفایل‌های موجود

- `generic`: هسته عمومی برای هر نرم‌افزار
- `wordpress-plugin`: افزونه وردپرس و ووکامرس/LearnDash
- `webapp`: وب‌اپلیکیشن
- `api-service`: سرویس API
- `religious-product`: لایه تکمیلی محصولات دارای قرآن، حدیث و محتوای دینی حساس

برای ترکیب پروفایل‌ها، گزینه `--profile` را چند بار تکرار کنید.

## اصل قطعی

«صفر خط کدنویسی دستی» به معنای «صفر نظارت» نیست. هیچ عامل هوش مصنوعی حق ادغام مستقیم در شاخه اصلی، دسترسی آزاد به اسرار، حذف داده اصلی یا انتشار بدون تأیید را ندارد.
