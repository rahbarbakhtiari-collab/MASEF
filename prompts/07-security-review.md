# پرامپت بازبینی امنیت

Threat Model و تغییرات را مستقل بررسی کن.

- ورودی، مجوز، احراز هویت، Session، CSRF، XSS، SQL Injection و SSRF متناسب با پلتفرم
- Secret، لاگ و داده شخصی
- وابستگی و زنجیره تأمین
- دسترسی Codex، Skill و MCP
- Prompt Injection از داده یا وب
- عملیات مخرب و راه بازگشت

هر یافته باید شامل مکان، سناریوی سوءاستفاده، شدت، شواهد، راه اصلاح و تست جلوگیری از تکرار باشد.
