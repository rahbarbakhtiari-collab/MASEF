# سیاست صحت و امانت محتوای دینی

## محدوده

این سند برای آیات، ترجمه قرآن، روایات، ادعیه، فتاوا، منابع و نسبت‌دادن سخن به معصومان علیهم‌السلام اجرا می‌شود.

## قواعد قطعی

- عامل حق تولید یا حدس‌زدن منبع دینی را ندارد.
- متن مرجع قرآن باید از Dataset تأییدشده و قفل‌شده دریافت شود.
- متن عربی مرجع بدون فرایند تغییر رسمی اصلاح نمی‌شود.
- ترجمه باید نام مترجم و نسخه منبع داشته باشد.
- روایت باید منبع، جلد/باب/صفحه یا شناسه قابل پیگیری داشته باشد.
- اختلاف نسخه‌ها به انسان گزارش می‌شود؛ عامل یک نسخه را خودسرانه برنمی‌گزیند.
- هر تغییر داده مرجع باید باعث شکست تست یکپارچگی شود.
- انتشار محتوای دینی حساس نیازمند تأیید انسانی مستقل است.

- گزارش هر تغییر حتی یک نویسه
