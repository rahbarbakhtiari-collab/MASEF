## ۹. سیاست‌های ثابت پروفایل WordPress

برای پروژه `wordpress-plugin` این موارد بدون نیاز به تصمیم دوباره اعمال می‌شوند:

- حداقل PHP `8.1+`
- خط مبنای WordPress برابر آخرین نسخه پایدار رسمی در زمان تأیید این منشور است.
- نسخه پایدار رسمی بررسی‌شده:
- تاریخ و منبع بررسی WordPress.org:
- نسخه‌های Alpha، Beta و RC خط مبنای Production نیستند.
- سازگاری پایین‌تر از نسخه ثبت‌شده هدف نیست.
- رابط فارسی و RTL، ولی ترجمه‌پذیر و سازگار با LTR
- آمادگی WordPress.org از نسخه نخست
- نویسنده `رهبر بختیاری` و مجوز `GPL-2.0-or-later`
- حفظ داده در Deactivation و Uninstall پیش‌فرض
- حذف کامل داده فقط با گزینه صریح و پیش‌فرض خاموش
- بدون Telemetry و ردیابی پیش‌فرض
- مخزن ابتدا Private و پس از آمادگی انتشار Public
- نصب نهایی Production توسط مالک محصول

مقدار نمونه راستی‌آزمایی‌شده در ۲۰۲۶/۰۷/۲۸: WordPress `7.0.2`.

مرجع: `docs/00-governance/WORDPRESS-PLUGIN-FACTORY-POLICY.md`

## ۱۰. اختیار Codex

Codex مجاز است تصمیم‌های فنی، طراحی، پیاده‌سازی، تست، رفع خطا، مستندسازی، ساخت محیط آزمایشی، GitHub و بسته‌بندی را در محدوده خلاصه تأییدشده مستقل انجام دهد.

Codex باید ابهام فنی را با ابزار، مستندات، پژوهش، Spike و آزمون حل کند و نباید مالک محصول را برای انتخاب‌های فنی معمول متوقف کند.

## ۱۱. موارد تصمیم انسانی پس از تأیید خلاصه

- تغییر اساسی نتیجه یا محدوده محصول؛
- هزینه یا خرید جدید؛
- Secret، ورود حساب یا مجوز انسانی؛
- حذف داده مهم یا اقدام برگشت‌ناپذیر؛
- استقرار پرخطر روی Production؛
- پذیرش خطر امنیتی، حقوقی یا سازمانی.
