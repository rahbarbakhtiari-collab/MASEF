## ۸. اختیار Codex

Codex مجاز است تصمیم‌های فنی، طراحی، پیاده‌سازی، تست، مستندسازی و Git را در محدوده این منشور مستقل انجام دهد.

مواردی که تصمیم انسانی می‌خواهند:

- تغییر نتیجه یا محدوده محصول؛
- هزینه جدید؛
- دسترسی محرمانه؛
- حذف داده مهم یا اقدام برگشت‌ناپذیر؛
- استقرار پرخطر روی Production؛
- پذیرش ریسک امنیتی، حقوقی یا سازمانی.
