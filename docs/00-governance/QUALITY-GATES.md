# دروازه‌های کیفیت

| کد | دروازه | شرط عبور | شواهد |
|---|---|---|---|
| G0 | اعتبار ایده | مسئله، مخاطب و نتیجه روشن است | منشور پروژه |
| G1 | آمادگی محصول | نیازمندی و معیار پذیرش تأیید شده | REQUIREMENTS و ACCEPTANCE |
| G2 | آمادگی طراحی | معماری، داده و تهدیدها بررسی شده | Architecture، ADR، Threat Model |
| G3 | آمادگی Harness | تست پایه، CI و قواعد عامل آماده است | اجرای validate و CI سبز |
| G4 | تکمیل پیاده‌سازی | معیارها با تست پوشش یافته‌اند | گزارش تست |
| G5 | بازبینی مستقل | بازبین مستقل مشکل مسدودکننده ندارد | Review Report |
| G6 | محیط آزمایشی | مسیر واقعی کاربر موفق است | تصاویر، لاگ و E2E |
| G7 | آمادگی انتشار | پشتیبان و بازگشت آزمایش شده | Evidence Pack |
| G8 | پس از انتشار | سلامت، خطا و شاخص‌ها کنترل شده‌اند | Post-release Report |

## سیاست استثنا

دورزدن دروازه فقط با ثبت این موارد ممکن است:

- علت؛
- خطر پذیرفته‌شده؛
- مالک خطر؛
- تاریخ انقضا؛
- برنامه جبران.
