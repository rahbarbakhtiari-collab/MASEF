# سیاست امنیت

## اصول

- کمترین سطح دسترسی
- رد پیش‌فرض
- جداسازی محیط توسعه، تست و اصلی
- اسرار خارج از مخزن
- ثبت رویدادهای حساس بدون ثبت خود داده حساس
- اعتبارسنجی ورودی در سمت سرور
- Encoding خروجی متناسب با Context
- عملیات حساس همراه Nonce/CSRF Protection و بررسی مجوز
- وابستگی‌های محدود و نسخه‌بندی‌شده
- شکست امن و پیام خطای غیرحساس

## دسترسی Codex

### مجاز بدون تأیید

- خواندن کد و اسناد غیرحساس
- تغییر فایل‌های Workspace
- اجرای تست محلی بدون شبکه

### نیازمند تأیید

- شبکه
- نصب وابستگی
- تغییر Schema
- دسترسی به سرویس خارجی
- عملیات روی محیط مشترک

### ممنوع

- چاپ یا انتقال Secret
- دسترسی مستقیم به Production
- حذف انبوه داده
- خاموش‌کردن کنترل امنیتی
- `--dangerously-bypass-approvals-and-sandbox` خارج از Container ایزوله و مجاز
