# مدیریت اسرار

## ممنوعیت‌ها

- Secret در کد، Markdown، Issue، PR، تصویر یا لاگ ثبت نشود.
- کاربر نباید کلید واقعی را در گفت‌وگو ارسال کند.
- فایل `.env` واقعی Commit نشود.

## محل‌های مجاز

- متغیر محیطی سیستم
- GitHub Actions Secrets
- Secret Manager ارائه‌دهنده زیرساخت
- فایل محلی خارج از مخزن با Permission محدود

## فرایند نشت احتمالی

1. توقف استفاده از کلید
2. لغو/چرخش کلید
3. بررسی تاریخچه Git و لاگ‌ها
4. حذف از تاریخچه در صورت نیاز
5. ثبت Incident بدون تکرار مقدار Secret
6. اصلاح Harness برای جلوگیری از تکرار
