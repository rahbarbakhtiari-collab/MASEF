# سیاست پشتیبان‌گیری

## محدوده

- کد و Release Artifact
- پایگاه داده
- فایل‌های بارگذاری‌شده
- تنظیمات غیرمحرمانه
- نگاشت نسخه نرم‌افزار و Schema

## اعتبار پشتیبان

پشتیبان فقط زمانی معتبر است که:

- زمان و نسخه آن مشخص باشد؛
- Hash یا اندازه ثبت شود؛
- محل نگهداری جدا باشد؛
- دسترسی آن محدود باشد؛
- بازیابی آن دوره‌ای آزمایش شده باشد.
