# راه بازگشت

## Triggerهای بازگشت

- خطای بحرانی
- ازبین‌رفتن داده
- شکست مسیر اصلی کاربر
- افزایش غیرعادی خطا
- ناسازگاری Schema
- خطای محتوای دینی

## روش

1. توقف انتشار/ترافیک جدید در صورت نیاز
2. ثبت نسخه و وضعیت فعلی
3. بازگرداندن Artifact قبلی
4. اجرای Down Migration فقط اگر امن و آزمایش‌شده است؛ در غیر این صورت Restore
5. Smoke Test
6. بررسی داده و لاگ
7. ثبت Incident
