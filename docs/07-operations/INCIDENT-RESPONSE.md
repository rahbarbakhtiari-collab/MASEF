# پاسخ به رخداد

## شدت

- SEV-1: خطر داده/امنیت/محتوای دینی گسترده
- SEV-2: مسیر اصلی از کار افتاده
- SEV-3: اختلال محدود
- SEV-4: نقص کم‌اثر

## مراحل

1. تشخیص و حفظ شواهد
2. مهار
3. تصمیم Rollback یا Fix-forward
4. بازیابی
5. اطلاع‌رسانی متناسب
6. تحلیل علت ریشه‌ای
7. افزودن تست/قاعده برای جلوگیری از تکرار

## ممنوعیت

در گزارش رخداد، Secret یا داده شخصی خام درج نشود.
