# راهنمای انتشار

## محیط‌ها

| محیط | هدف | داده | دسترسی |
|---|---|---|---|
| Local | توسعه | ساختگی | عامل/توسعه‌دهنده |
| Test/Staging | تأیید | پاک‌سازی‌شده | محدود |
| Production | استفاده واقعی | واقعی | حداقل افراد |

## پیش‌شرط انتشار

- [ ] G0 تا G7 عبور کرده‌اند.
- [ ] نسخه و Changelog آماده است.
- [ ] Backup تأیید شده است.
- [ ] Rollback آزمایش شده است.
- [ ] مهاجرت داده روی Staging موفق است.
- [ ] پنجره انتشار و مسئول پاسخ مشخص است.

## مراحل انتشار

1. ایجاد Tag/Release Candidate
2. پشتیبان‌گیری
3. فعال‌سازی Maintenance در صورت نیاز
4. انتشار Artifact ثابت
5. اجرای مهاجرت
6. Smoke Test
7. بررسی لاگ و شاخص‌ها
8. اعلام نتیجه یا Rollback
