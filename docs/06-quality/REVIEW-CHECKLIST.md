# چک‌لیست بازبینی مستقل

## انطباق با هدف

- [ ] تغییر دقیقاً مسئله تعریف‌شده را حل می‌کند.
- [ ] قابلیت خارج از محدوده اضافه نشده است.
- [ ] همه معیارهای پذیرش پوشش داده شده‌اند.

## درستی

- [ ] خطاهای مرزی، null، تکرار و هم‌زمانی بررسی شده‌اند.
- [ ] تست‌ها واقعاً شکست احتمالی را تشخیص می‌دهند.
- [ ] Mock بیش‌ازحد باعث تست مصنوعی نشده است.

## امنیت

- [ ] ورودی و مجوز سمت سرور بررسی می‌شود.
- [ ] Secret یا داده حساس نشت نکرده است.
- [ ] وابستگی یا شبکه جدید توجیه شده است.
- [ ] عملیات مخرب محافظت دارد.

## نگهداری

- [ ] طراحی با معماری پروژه سازگار است.
- [ ] پیچیدگی بی‌دلیل و کد تکراری اضافه نشده است.
- [ ] مستندات و راه بازگشت کافی‌اند.
