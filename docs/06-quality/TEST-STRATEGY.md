# راهبرد آزمون

## هرم آزمون

1. تست واحد برای منطق دامنه
2. تست یکپارچه برای پایگاه داده و سرویس‌ها
3. تست E2E برای مسیرهای حیاتی کاربر
4. آزمون دستی فقط برای مواردی که خودکارسازی آن ارزش ندارد

## قواعد

- Bug fix باید در صورت امکان ابتدا تست شکست‌خورده داشته باشد.
- تست نباید به ترتیب اجرا وابسته باشد.
- زمان، شبکه و داده تصادفی باید کنترل شوند.
- داده تست از Production کپی خام نشود.
- مسیر خطا به‌اندازه مسیر موفق آزموده شود.
- تست‌های حیاتی در CI اجباری‌اند.
